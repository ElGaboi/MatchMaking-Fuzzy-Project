# Matchmaking-Fuzzy-
Projeto em desenvolvimento!

Pasta Código_Base_InputManual: Subsistema simples que apenas calcula o grau de consistência de um único jogador.

Pasta Código_DatasetComoInput: roda o dataset e classifica todos os jogadores.

Pasta Parte_Final: Código faz a classificação de uma partida e diz se ela é boa ou ruim, utilizando como entrada o dataset de saída do sistema anterior.

Todas as imagens estão em suas respectivas pastas relacionadas às estapas.

CSV terminando coom "output" é a saída do primeiro sistema, que está na pasta "Código_DatasetComoInput". A segunda etapa está na pasta "Parte_Final".
